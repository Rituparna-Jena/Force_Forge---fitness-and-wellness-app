First run: point the bouncer at a brain

Paste a Groq API key (create one at console.groq.com/keys). It is written to a local config file that git ignores, read only by this server process, and never sent to the browser or the extension. No key? Run in mock mode instead; the whole app works with canned verdicts.

Prefer the file? Copy .env.example to .env and set GROQ_API_KEY. This form writes data/config.json, which wins over the .env value and hot-reloads without restarting.

What this prototype logs

Your excuse text, the site name, the timestamp, the energy level you reported, the verdict, and the need category the model inferred. That is the entire list. It never reads page content, never stores URLs beyond the site label, never records titles, and nothing leaves your machine except the excuse text and energy level sent to the LLM provider you configured. The key you paste lives in a local git-ignored file and is used only for outbound calls from the server.

Usage terms, in plain words

This is a research prototype, not a product and not therapy. It judges excuses and it can be wrong, including about distress. If you are in crisis, contact your local emergency number or a crisis line; this tool is not that. All data stays in a local database on your machine. To erase everything this prototype knows about you, use the delete all data button above, or DELETE /data against the server. Deleting is immediate and complete.
